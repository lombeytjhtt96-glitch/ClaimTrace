# antislop (Core Filter)

> Anti Slop: Rules for AI Coding Agents. A filter, not a style guide.

## Usage Mode
- **Mode 1 (During):** Apply rules while generating code and UI.
- **Mode 2 (After):** Audit existing work, produce numbered findings list citing R-XX rules, seek approval, fix, and deliver follow-up report.

## The Craftsmanship Standard
- **C-1 Intentionality:** Every visual and copy decision must have an articulable purpose.
- **C-2 Functional Completeness:** Every interactive element must work or not exist. No non-functional buttons or placeholders.
- **C-3 Content-Driven Composition:** Layout serves the healthcare domain data, not a generic template.
- **C-4 Resilience:** UI holds up across empty, loading, error states, and responsive breakpoints.
- **C-5 Evidence Over Claims:** Real verifiable data, formulas, and legal references over vague AI marketing claims.

## Hard Gate Rules
- **R-02:** No unmotivated floating glows, full-screen radial orbs, or harsh rainbow gradients.
- **R-03:** No excessive pill-shaped buttons or generic floating glass cards everywhere.
- **R-17:** Contrast ratio must strictly pass WCAG AA (minimum 4.5:1 for normal text).
- **R-18:** Interactive elements must have clear focus, hover, and active states with minimum 44x44px touch targets.
- **R-23 to R-28:** Real content only; no fake metrics, placeholder lorem ipsum, or invented testimonials.
- **R-37:** Purpose-Driven Direction: Ground design in domain identity (BPJS Kesehatan / Healthcare Verifier System).
